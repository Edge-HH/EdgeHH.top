这个站点用来集中展示我做的几个项目，并记录它们的变化。

## 这里有什么

- **项目**：首页可以依次浏览 [RemoteCI](/projects/remoteci/)、[Pancake](/projects/pancake/) 和 [ClipPort](/projects/clipport/)，每个项目都有单独的介绍页。
- **文章**：版本更新日志、开发过程中的笔记，以及一些零散的想法。和某个项目相关的文章，也会出现在那个项目页的「更新日志」里。

## 留言

文章底部的评论区基于 GitHub Discussions，用 GitHub 账号登录就可以留言。有问题或建议，也欢迎直接到对应项目的仓库提 Issue。
