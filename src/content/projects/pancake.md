## 看板

- 默认以全屏展示模式启动，深色看板；也支持浅色和跟随系统，以及普通窗口模式。窗口很窄时自动改为上下排列。
- 时钟区显示时间（带秒）、日期、天气和教室噪音。
- 天气：输入地区名称搜索，内置 2566 个地区，显示当前温度和天气状况。数据来自社区整理的小米天气接口文档，不是官方开放接口，服务端变化时可能需要适配。
- 噪音检测：用麦克风实时估算环境音量，可以设置检测间隔、输入设备、吵闹阈值、提示音音量，并按目标音量校准。麦克风数据只用来计算音量，不录音，也不保存。噪音数值是估算值，不等于专业声级计读数。

## 布局

- 四种布局：分屏、仅作业、仅时钟和自由布局。分屏时拖动中间的分隔条调整两区大小，拖到两端就进入单区；“仅作业”和“仅时钟”会把分隔条留在屏幕边缘，可以随时拖回分屏。
- 磁贴默认吸附到 48 px 网格，网格大小可以调整。关闭网格后，拖动磁贴会吸附到作业区中轴和其他磁贴的边缘、中心线，并显示蓝色辅助线。
- 无限作业板：作业多时可以滚动、平移和缩放，拖到边缘会继续扩展。编辑时右侧的缩放岛可以连续调整比例，点比例数字回到 100%。
- 自动排列：先把一行排满再换行，可以设置磁贴最小间隔、自动对齐和自动调整大小；内容放不下时等比缩小磁贴。

## 编辑作业

- 查看模式下，浮动控制窗依次是“编辑看板”“设置”“全屏切换”。进入编辑前会自动保存一份快照：底栏倒数第二个按钮在确认后放弃本轮全部修改，最后一个按钮保存。
- 新增、重命名、移动、缩放和删除科目磁贴；拖动磁贴顶部移动，拖动边角调整大小。每个科目可以单独设置主题色。
- 直接在磁贴里写作业。点击文字后，控制窗旁的富文本岛提供字体、加粗、斜体、下划线、文字颜色和高光；有选区时只改选中的文字。
- 插入图片：按原图比例显示，可以拖动、按四角等比缩放、裁切、旋转和复位。加入的图片会复制到项目的资源目录，不改动原文件。
- 自动填充（默认关闭）：输入科目名时按学科补全标题，支持中文、全拼和首字母，并套用学科颜色；还能按学科补全常输入的作业名称。记录只保存在本机。
- 按 `Esc` 先结束当前编辑；没有在编辑时再按一次，退出全屏。

## 手写批注

- 编辑模式底栏第一个按钮打开全局画笔，画笔栏提供颜色、细中粗三档、橡皮擦，以及按磁贴或全部清空。
- 每一笔归属于起笔的那个磁贴，超出磁贴的部分不会落笔；缩放磁贴不会把已有笔迹一起拉伸。
- “仅时钟”模式下可以在整个屏幕上书写，笔迹随项目保存。

## 项目、作业文件与导出

- 一个“项目”就是一套看板，项目默认按创建日期命名。顶栏左上角随时切换最近项目，并显示科目数量；新建时可以只清空作业内容、保留科目和布局，也可以从空白开始。
- `.pch` 作业文件把布局、配色、富文本、图片和可编辑的笔迹打包在一起，导入后可以继续修改并保存回原文件。缺少附件时会明确报错，不会生成残缺的文件。
- 图片导出：选择常用比例或自定义尺寸，调整背景、色系、标题字体字号、磁贴位置和缩放，导出不含时钟和编辑工具的 PNG，适合发到班级群。

## 外观

- 控制窗：可放在屏幕下方、上方、左右等 8 个位置，调整大小、圆角、边框、边距，选择是否显示按钮名称、是否自动隐藏。
- 编辑时控制窗两侧出现两块悬浮岛：一侧是富文本工具（打开画笔时换成画笔控件），另一侧是作业板缩放。它们和控制窗共用圆角、背景、毛玻璃和大小设置。
- 磁贴：标题大小，正文默认字号、字体、粗体和斜体，背景颜色、透明度和毛玻璃。
- 组件和时钟：天气、噪音组件卡的背景与模糊；时钟的字体、粗细和颜色。
- 背景：时钟区、作业区可以分别设置，也可以在分屏时共用一张跨区背景。支持 PNG、JPEG、BMP、WebP、GIF 图片和 MP4、MOV、WebM 等视频，还能设成播放队列，按固定时间或视频播完时切换。
- 内置 HarmonyOS Sans 字体和 Fluent System Icons 图标字体。

## 数据、锁定与更新

- 所有项目和设置持续自动保存到程序旁的 `data` 目录。也可以关闭自动保存，只在退出、切换项目或手动保存时写盘。
- 备份：按范围导出 `.pbk` 备份（作业数据、当前背景、最近背景、软件设置可任意组合），从备份还原后自动重启加载；还可以按目录、间隔和保留份数定期自动备份。
- 锁定：可以设置密码（只保存 PBKDF2-SHA256 哈希）和验证器两步验证（TOTP，绑定时直接显示二维码），分别要求“打开设置前”和“编辑看板前”验证。开了锁定但没设密码和验证器时不会锁住，避免把自己关在外面。
- 自动更新：默认从 GitHub Releases 检查，也可以改用 Gitee；支持 ZIP、7z 和分卷更新包。确认后先保存项目，校验解压后覆盖并重启，不会覆盖 `data`；覆盖失败会尝试恢复旧文件。关于页可以随时查看最新版本的更新说明。

## 启动参数

| 参数 | 作用 |
| --- | --- |
| `--windowed` | 以普通窗口启动 |
| `--fullscreen` | 以全屏启动（默认） |
| `--view=editor` | 启动后直接进入编辑模式 |
| `--view=ink` | 启动后直接进入可以手写的编辑模式 |
| `--view=settings` | 启动后直接打开设置 |
| `--project=<项目名或 .pch 路径>` | 打开指定项目；给出 .pch 路径时先导入再打开 |

关闭“允许多实例”后，再次运行带参数的命令会把参数交给已经打开的窗口执行，不用先关掉再开。

## 安装与系统要求

- Windows 10 1809（17763）或更高版本，x64 设备。
- 在 [Releases](https://github.com/Edge-HH/Pancake/releases/latest) 下载 `Pancake-win-x64` 压缩包，完整解压后运行 `Pancake.exe`。压缩包已自带 .NET 和 Windows App SDK 运行资源，不需要另外安装。不要只复制单个 exe，也不要放在没有写入权限的目录。
- 触屏手势、触控笔压感和不同大屏上的显示比例，作者仍在实际设备上继续验证。
